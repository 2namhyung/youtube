## API and data contract

- New job kind: canonical-cut-preview. Fixed episode ID episode-001 initially; API accepts only current projectId, baseRevision, sceneId and idempotencyKey plus action/kind. Resolve scene -> exactly one originCutId -> current catalog composition internally. Reject all custom paths, code, props, URLs, codec, size, duration, approval and runtime options.
- Studio source is an exact current episode-spec-bound imported plan. A freeform project, stale origin hash, merged/ambiguous/missing originCutId or unadopted editorial changes cannot request a canonical preview. Explain that the rendered content is the adopted episode specification, never the unadopted Studio candidate. Candidate selection/lock/source observations do not grant eligibility.
- Read-only GET /api/studio/cut-render-contract?id=...&baseRevision=...&sceneId=... returns visualmaker-canonical-cut-render-v1: scope(project/revision/scene/cut), Plan snapshot and script SHA, fixed episode ID, exact authority input fingerprints or null, structured blockers, validator observations (not inferred from state labels), selected canonical composition or null. productionAuthority=false, cutPass=false, stylePass=false, playableParity=false. renderEligible may be true only when the complete current canonical render preflight really passes, not merely declared status strings or file presence. Missing/blocked input is an honest report, not a 500/path leak. Invalid scope 400, no auth 403, stale revision 409, missing project 404. no-store.
- Queue acceptance uses the same evaluator. Persist an immutable execution-contract JSON and SHA-256 separate from the Plan snapshot in the job record; migration must preserve existing jobs. Idempotent replay returns the original job/contract, including stale baseRevision, when every caller scope field matches; different scene/kind/key scope conflicts. Blocked jobs store their immutable reason/contract but cannot run. A fresh enqueue is required after inputs or approvals change.
- Client verifies response schema/project/revision/scene/Plan snapshot hash and authority flags. Render is only offered for a verified eligible report; API rechecks regardless of UI. Abort and primitive scope/epoch checks prevent stale report/job/video across project/revision/scene/attempt changes. Bound playback to response job/project/attempt headers; revoke owned blob URLs on replacement/unmount.
