# Data animation

## Principles

- Preserve object identity when changing views.
- Stage multi-property changes rather than changing position, size, color, and chart type simultaneously.
- Animate one meaningful change, then hold the result for reading.
- Keep axes, units, date range, and source visible.
- Never use movement to imply that one event caused another without evidence.

These principles are grounded in research on graphical perception and object constancy. Source: [animated-transition research](../../raw/sources/animated-transitions-and-sound-2026-08-21.md#animated-data-transitions)

## 23jung pattern

`question → static baseline → one transition → reading hold → verbal interpretation → provenance`

## Uncertainty

No single optimum transition length is established for all charts; timing depends on complexity and viewer familiarity. Source: [research cautions](../../raw/sources/animated-transitions-and-sound-2026-08-21.md#cautions)
