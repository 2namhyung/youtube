## 1. 이 영상이 답할 질문

> 중고거래 사기를 당해 경찰에 신고했는데 중요한 확인이 빠졌다면, 2026년 10월 2일부터 누가 무엇을 다시 확인하게 될까?

시청자가 기억해야 할 것은 세 가지다.

1. 개정 형사소송법은 검사가 직접 수사할 일반적 법적 근거를 삭제한다.
2. 경찰이나 다른 수사기관에 보완수사를 요구하는 절차는 남고 더 구체화된다.
3. 이 변화가 실제 사건 처리에 미칠 결과는 시행 후 데이터로 확인해야 한다.

SH001–SH048 전체가 개별 PASS된 뒤에만 이 일곱 키프레임을 Omni MP4로 영상화한다. SH015에서 사건파일로 전환한다. Omni 화면에는 제목·해설문·말풍선을 붙이지 않는다. 이후에도 독립적인 텍스트 박스는 사용하지 않고 실제 문서, PNG 사물, 경로, 숫자와 단어 수준의 표지만 사용한다.

## 5. 컷 폴더 계약

각 행은 반드시 하나의 실제 폴더다. 특히 SH001~SH005를 한 폴더 안의 다섯 장면으로 합치지 않는다.

```text
video/public/assets/<future-reviewed-root>/cuts/SH###/
├─ background.png                 # 고정 베이지 체크 배경, 항상 존재
├─ assets/                        # 컷에서 실제로 쓰는 PNG·문서·차트
├─ effects/                       # effects_required=true일 때만 생성·실제 파일 저장
├─ manifest.json                  # 모드·프레임·출처·전환·final hold
├─ omni/                          # Omni 컷만
│  ├─ start.png
│  ├─ end.png                     # 필요한 경우
│  ├─ output.mp4                  # SH001~SH048 48/48 PASS 뒤에만 생성
│  ├─ prompt.json
│  └─ qc.json
├─ source-photo/                  # 실제 문서·사진 컷만
├─ source-video/                  # 실제 영상 컷만, 원본 timecode 포함
└─ remotion/                      # Remotion 컷의 구성·프레임 노트
```

- 모든 Remotion 컷은 `빈 배경 → asset/effect 등장 → 모든 요소가 보이는 final hold`로 끝난다.
- 모든 활성 컷은 배경·manifest 외에 mode별 실제 로컬 시각 입력을 최소 하나 가진다. 빈 폴더·README·JSON·`.gitkeep`·placeholder는 자산으로 세지 않는다.
- `remotion`은 `assets/`의 PNG·SVG, `source-photo`는 실제 이미지, `source-video`는 실제 영상, `omni`는 첫 검수 단계에서 imagegen PNG 키프레임을 필수로 한다. 이 파일들은 manifest `assets`에도 등록한다.
- 컷별 `review.user_pass`가 SH001~SH048 모두 true이고 episode cut-review marker가 48/48을 확인하기 전에는 파일명·확장자를 불문하고 어떤 Omni 동영상도 생성·수급·참조하지 않는다.
- 컷별 PASS에는 검수한 실제 asset, imagegen 키프레임과 선언된 effect의 SHA-256을 기록하고, SH001~SH048의 `컷 ID + 종류 + 경로 + 실제 SHA-256` 집계값을 episode cut-review marker에 결속한다. 검수 뒤 파일이 바뀌면 집계값 불일치로 PASS를 무효화하고 해당 컷을 다시 검수한다. 고정 배경의 복제본은 컷 asset이나 키프레임으로 세지 않는다.
- Remotion→Remotion 경계도 내용상 단절이 맞으면 hard cut을 허용한다. reference-derived hard cut은 승인 grammar와 의미를 결속하고 adjacent zero-blend frame으로 증명한다. `shared-element`/`scene-to-scene`을 선택한 경우에만 outgoing/incoming component·asset과 trajectory를 기록한다.
- Omni→Omni는 이전 클립의 마지막 자세·소품 위치를 다음 시작 프레임과 일치시킨다. 한 클립에는 하나의 중심 행동만 둔다.
- Omni 영상 위에는 제목·설명문·말풍선·콜아웃을 붙이지 않는다. AI 사용 고지는 행동 플레이트 밖의 공통 크레딧과 설명란에서 처리한다.
- 실제 문서에 보이는 글자는 증거이므로 허용한다. 별도 텍스트는 날짜·숫자·`미확인`·`사실확인` 같은 단어 수준으로 제한한다.
- 효과 파일은 분위기 보조일 뿐 사실 근거가 아니다. `effects_required: true`이면 실제 파일·출처·checksum이 필요하고, `false`이면 빈 `effects/` 폴더를 완료 상태처럼 남기지 않는다. 실제 사건처럼 오해시키는 폭발·연기·충격 효과를 넣지 않는다.

여기서 `faithful reference reproduction`은 픽셀 1:1 복사가 아니라 `reference-derived grammar prototype`이다. 후보 소재는 교체할 수 있지만 관찰된 시각 문법만 사용한다.

### Grammar allowlist 적용

이번 보정에서 reference still·timecode·side-by-side는 원본과 후보를 픽셀 1:1로 복사시키는 목표가 아니라, 어떤 화면 문법을 관찰했는지 고정하는 locator로 정의했다. EP001의 소재는 우리 공식·실사 source로 교체할 수 있다. 단, 모든 visible component/action/transition/treatment는 [reference grammar contract](../../video/episodes/episode-001/reference-grammar-contract.json)의 관찰 ID에 결속해야 하며, 미관찰 설명 카드·범용 텍스트박스·아이콘·효과·전환을 추가할 수 없다. `unmapped_visual_grammar=[]`, `novel_visual_grammar=[]`가 아닌 후보는 PASS 경로에서 거부한다. beige checker background·source/rights chrome·source-locked legal retype은 비초점 compliance 예외로만 허용한다. Source: [grammar validator](../../video/scripts/validate-reference-style-gates.mjs), [reference grammar contract](../../video/episodes/episode-001/reference-grammar-contract.json), [locked reference analysis](../sources/vox-style-claude-remotion-reference.md).
