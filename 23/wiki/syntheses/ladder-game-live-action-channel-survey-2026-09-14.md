## 채널에서 반복 확인되는 실사 편집 규칙

1. **실사는 명사 하나가 아니라 의미 사슬로 수집한다.** 인물/기관·장소·행동·도구·결과를 별도 원본으로 준비한다.
2. **한 visual beat 안에는 한 focal만 둔다.** full-frame 실사 위에 자막은 붙지만, 여러 실사를 같은 크기로 늘어놓는 박물관식 배열은 특별한 비교·집단 의미가 있을 때만 사용한다.
3. **같은 주제의 반복은 거리와 행동으로 푼다.** 외관 와이드 → 내부 업무 → 손/도구 클로즈업 → 결과 화면처럼 semantic subject/action을 바꾼다. 단순 crop은 새 컷으로 세지 않는다.
4. **관계·수치·단계는 그래픽이 담당한다.** 실사는 대상을 보여주고, exact relationship·수치 비교·절차 이동은 표·구조도·독립 레이어로 전환한다.
5. **인터뷰는 말하는 사람 자체가 증거일 때 유지한다.** 무조건 2–4초로 자르지 않고 발언의 완결까지 hold한다. 발언 중 B-roll은 발언의 구체 사례가 있을 때만 삽입한다.
6. **추상 문장에는 generic stock을 강제하지 않는다.** 책, 손그림, 반복 캐릭터, 원 발언, 문장 표면처럼 개념에 맞는 설명 형식을 사용한다.
7. **전환은 대부분 의미 단위 hard cut이다.** 화려한 효과보다 내레이션의 다음 명사·행동·사례에 맞춰 화면 대상이 바뀐다. 동일 object가 관계 설명을 이어갈 때만 object-preserving reframe이 적합하다.
8. **화면 자료는 UI·표·기사 자체가 분석 대상일 때만 쓴다.** 웹/앱 화면을 분위기용 배경으로 재사용하지 않는다.

## EP001에 적용할 수정 기준

현재 소스 수집은 ‘문서 업무’, ‘기관’, ‘타이핑’ 같은 넓은 검색어에서 멈추기 때문에 같은 책상·서류·건물 원본이 반복된다. Ladder Game 방식으로 바꾸려면 각 컷의 검색 brief를 아래 다섯 슬롯으로 분해해야 한다.

| 슬롯 | 질문 | SH012 적용 | SH013 적용 |
|---|---|---|---|
| actor/institution | 누가·어느 기관인가 | 증거를 검토하는 담당자, 특정 사건 당사자는 아님 | 경찰 맥락과 검찰 맥락을 각각 확보 |
| place/context | 어디인가 | CCTV/DVR가 있는 보안·기록 검토 환경 | 경찰 기록 보관/인계 지점과 검찰 접수 지점 |
| action | 무엇을 하는가 | 저장매체 분리·연결·영상 확인·누락 비교 | 기록 봉투를 봉인·운반·수령하는 동작 |
| object/detail | 어떤 물체가 의미를 고정하는가 | CCTV 카메라, DVR, 저장장치, 재생 화면 | 동일 사건기록 묶음, 봉투, 수령 표시 |
| result/next state | 무엇이 달라졌는가 | 빠진 자료를 찾거나 재검토 상태가 됨 | 기록의 담당 위치가 경찰에서 검사로 이동 |

SH012는 source-video를 유지하되 `문서 스캔`을 배제하고, 장소 확립 영상과 실제 저장매체 검토 행동을 서로 다른 원본으로 구성한다. SH013은 정확한 기관 간 관계가 핵심이므로 경찰·검찰·사건기록의 실제 독립 원본을 확보한 뒤 Remotion에서 동일 기록 묶음을 보존하며 이동시키는 방식이 적합하다. generic 택배·문서함·필기 영상은 제거 대상이다. Source: [episode spec](../../video/episodes/episode-001/episode-spec.json), [현재 source review](../../video/qa/source-review/episode-001-source-selection-v02/review.html), [reference grammar contract](../../video/episodes/episode-001/reference-grammar-contract.json).

전체 컷에는 고정 개수 quota를 두지 않는다. 대신 각 실사 beat가 위 다섯 슬롯 가운데 실제 내레이션에 필요한 슬롯을 채웠는지, 인접 컷과 original SHA-256 및 semantic subject/action이 겹치지 않는지 검사한다. 관계·조건·기간을 실사 분위기로 대신하지 않고 Remotion으로 보낸다. 가상 사건 연속성만 Omni를 사용한다.

## 권리 한계
