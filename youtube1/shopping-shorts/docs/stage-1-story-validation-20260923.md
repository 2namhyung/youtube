# 이야기 우선 1단계 검증 — 2026-09-23

## 실행 결과

- 새 API 수집: 검색 3건 성공, 영상 70개 정규화, 같은 영상 70개의 통계 관측. 4번째 검색 HTTP 429, 채널 활동 조회 HTTP 403. 통계 관측은 별도 버킷으로 계속 진행됐다.
- 출처 4개와 주제 검토 4개를 계약으로 등록. 이야기·상품 연결 확인 3개, 일부 내용 관측 보류 1개. 관심 상승과 채널 활동까지 확인된 주제는 0개.
- 실제 본 자료: 스브스뉴스 한국어 자동 자막 전체, Sealed Air 역사 설명, The Strong 박물관의 Play-Doh 역사 설명, 푸딩 영상 일부 프레임·메타데이터·제한된 자동 자막. 자막이 제공되지 않은 두 후보 영상은 전체 내용을 확인했다고 기록하지 않았다.
- 실제 의미 검토는 GPT-6 현재 작업. Luna는 사용 가능한 선호 모델/운영 계약이며 이번 실행의 모델로 표시하지 않았다. 하위 에이전트·JEV·새 예약 실행 없음.

## 코드 및 화면 검증

- `python -m pytest tests -q`: 기존 44개 + 당시 신규 14개, 합계 58개 통과.
- 이후 시간창·본문 미완료·미래 관측·진행 중 인계 방지 검사를 추가. `python -m pytest tests/test_story_discovery.py -q`: 신규 테스트 총 18개 통과.
- `npm run build` (`apps/web`): TypeScript 검사와 Vite 프로덕션 빌드 성공.
- Chrome의 로컬 앱에서 초기 현황 70/4/0, 이야기·상품 연결 상세, 보류 상태 필터와 비활성 상품 조사 버튼을 확인했다.
- 앱 URL에 귀속되는 브라우저 오류 없음. 별도 브라우저 확장의 `ethereum` 주입 오류는 앱 코드와 구분했다.
- 라이브 API의 dashboard/packet 응답을 확인했고, 기존 8765 서버를 유휴 상태에서 업데이트된 코드로 재시작했다.
