# 쇼핑 쇼츠 구현·승인 이력

## 2026-09-23 · 사용자 진행 요청에 따른 1단계 구현

- `story-trend-commerce-v2` 수집기, 구조화 근거/검토, 현재 관심 계산, 로컬 화면, 프로젝트의 상품 조사 인계를 구현했다. 기본 화면과 1단계 메뉴는 주제 발굴이다.
- 첫 실배치: 새 검색에서 70개 영상, 4개 검토 주제, 4개 근거. 3개는 이야기/연결 확인, 1개는 내용 관측 부족. 현재 관심·채널 활동 게이트까지 통과한 주제는 0개다.
- 과거 채널 이상치·상품 태그 분류는 그대로 참고 자료다. 새 기준으로 자동 승격하지 않는다. 최근 90일 5개 업로드 기준은 유지한다.
- 독립 출처와 시계열 관측은 분리하며, 누적 조회수·검색 결과 제목·본문 읽은 날짜로 유행을 확정하지 않는다. 5단계 대본 계약 확장은 이번 1단계 구현 완료에 포함되지 않는다.
- 실제 의미 검토는 현재 GPT-6 작업에서 수행했다. Luna 호환 입력 계약을 제공하지만 실제 Luna가 실행됐다고 기록하지 않는다. 예약 생성/재개, JEV, 하위 에이전트 호출은 하지 않았다.

## 2026-09-23 · 썰 중심 1단계 재설계

- 사용자 정정: 메인은 썰이고 쇼핑은 사이드다. 상품 키워드로 쇼핑 채널을 늘리는 대신 현재 관심 주제와 자연스러운 상품 연결 가능성의 교집합을 찾아야 한다.
- 새 설계는 [stage-1-story-trend-commerce-v2.md](stage-1-story-trend-commerce-v2.md)에 기록했다. 1단계 결과를 채널/상품 목록에서 이야기 주제·각도·트렌드 근거·상품 연결 근거로 변경한다.
- 쇼핑 태그·유료 프로모션·쇼핑 키워드는 썰 후보의 필수 조건이 아니다. 기존 원자료는 보존하고 새 기준의 검증 결과로 자동 전환하지 않는다.
- 최근 90일 5개 업로드 활동 기준을 유지하되, 미수집은 비활성 확정과 구분한다. 전체 과거 영상 백필보다 최근 후보 주제와 비교군 관측을 우선한다.
- 이번 변경은 설계와 운영 안내다. 실행 코드·API·UI는 아직 기존 방식이며 새 방식의 수집·Luna 관측·배포 완료를 의미하지 않는다.

## 2026-09-22 · 신규 로컬 프로필

- 사용자 요청: 첨부된 shopping-shorts architecture/final audit를 실제 구현하고, 하위 에이전트 없이 직접 수행. JEV보다 Luna+computer use+Chrome use 경로를 우선 구축한다.
- 문서 속 JEV/Gemini/Azure 필수 공급자 선정은 사용자 요청보다 하위의 설계 자료로 취급했다. 핵심 데이터·시간·출처·동일 상품 게이트를 유지하고 공급자 경로를 `luna-browser-local-v1`로 분리했다.
- 기존 뉴스룸 프로젝트의 대본, 제목, owner voice, 거절/폐기 artifact를 반입하거나 승인으로 승격하지 않았다. 이 쇼핑 프로젝트에는 기존 승인/거절 영상 이력이 없다. 신규 script/title/voice는 각각 새 근거와 검수 기록을 요구한다.
- 기본 로컬 실행은 FastAPI/React/SQLite WAL/단일 영속 worker다. PostgreSQL/Prefect/WISE/Gemini/JEV/Azure 계정과 대형 모델 설치를 기본 전제로 두지 않는다. 선택 확장의 미구현·미검증 상태는 README와 capability 화면에 노출한다.
- 디코드·해시·렌더 계약은 코드가 검사한다. 의미 관측은 현재 운영자/Luna 작업의 근거와 진술이며 별도 독립 공급자 인증을 주장하지 않는다.
- 합성 smoke의 product/voice/review는 `fixture-no-model-executed`로 표시한다. 실제 상품, Luna/Gemini/JEV 실행, 실제 음성 품질, 검색 계정 성공을 주장하지 않는다.
- api.txt와 pixel.txt를 읽거나 복사하지 않았다. 원자료 폴더, 기존 모듈 output, 중첩 Git은 변경하지 않는다.

현재 변경은 로컬 앱 구현과 합성 검증의 권한이다. 실제 상품·내레이션·제목·게시의 일괄 승인이 아니다.


## 2026-09-23 · 상품 판단 전 이야기 검토와 예비 키

- 새 키를 사용자 환경 변수 `YOUTUBE_API_KEY_2`에 등록했다. 인증 만료/무효일 때만 자동 예비 전환한다. 일일 한도나 429 뒤에 다른 프로젝트 키로 전환하는 요청은 YouTube의 쿼터 우회 금지 정책에 맞춰 구현하지 않았다. 두 키 값과 비밀 파일은 코드·로그·보고서에 포함하지 않는다.
- 관계·직장·일상·취미·문화·호기심에서 이야기를 먼저 판단하는 중간 계약을 추가했다. 상품과 분리한 도입/변화/결말, 사실·창작 라벨, 같은 사건 묶음이 후속 트렌드/상품 검토의 입력이다. Chrome 자막 로드가 지연되는 사례가 있어 최초 내보내기 실패를 자막 영구 부재로 단정하지 않는다.
- 중간 검색 실패의 복구, 분야 순환, 요청별 예산 차감, 비밀 오류 비노출을 구현했다. 스케줄은 만들거나 재개하지 않았다. 신규 제작·영상 출력 계약 변경은 이 작업에 포함하지 않는다.
