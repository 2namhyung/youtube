# 한국 쇼핑쇼츠 검색어 조사

## 수집 원칙

- YouTube `search.list`에서 `regionCode=KR`, `relevanceLanguage=ko`, `videoDuration=short`를 사용한다.
- 검색 결과의 최신성과 누적 인기를 함께 보기 위해 검색어마다 `date`와 `viewCount` 순서를 실행 회차별로 교대한다.
- API 기본 검색 한도를 고려해 전체 검색어를 한 번에 호출하지 않고, 가장 오래 실행되지 않은 상품군부터 순환한다.
- `paid_promotion` 그룹은 `videoPaidProductPlacement=true`를 사용해 제작자가 유료 프로모션으로 표시한 영상을 우선 찾는다. 이 값은 YouTube Shopping 상품 태그와 동일하지 않으며 후보 발굴용 대리 신호다.
- 검색어는 기존 수집 영상 제목·설명의 반복 표현과 한국 쇼핑 콘텐츠에서 쓰이는 채널·플랫폼·구매 의도 표현을 결합했다.

## 검색어 세트

### 유료 프로모션 대리 신호 (`paid_promotion`)

`생활용품 추천 쇼츠`, `주방용품 리뷰 쇼츠`, `뷰티 제품 추천 쇼츠`, `전자제품 추천 쇼츠`, `패션 아이템 추천 쇼츠`, `육아용품 리뷰 쇼츠`, `반려동물 용품 쇼츠`, `캠핑용품 리뷰 쇼츠`, `건강식품 리뷰 쇼츠`, `식품 추천 쇼츠`

이 그룹은 공개 API가 제공하는 유료 프로모션 필터를 사용한다. 실제 쇼핑 스티커나 `제품 보기`는 Chrome 표본 검사로만 확인한다.

### 쇼핑태그 직접 신호 (`shopping_tag`)

`쇼핑하기 쇼츠`, `제품 보기 쇼츠`, `유튜브 쇼핑 제품 태그`, `영상 속 제품 스티커`, `쇼핑태그 추천템`, `제품 태그 쇼츠`, `유튜브쇼핑 추천템`, `쇼핑 스티커 쇼츠`

Chrome 표본 검사에서 일반 `리뷰`, `제품`, `아이템`만 포함된 영상은 오탐이 많았다. 이 단어들은 단독 쇼핑 신호로 인정하지 않고 두 개 이상이 함께 나타날 때만 약한 쇼핑 신호로 사용한다. `추천템`, `꿀템`, `파트너스`, 구매 링크 표현과 위 쇼핑태그 직접 신호는 강한 신호로 유지한다.

Chrome 판정은 Shorts 화면의 실제 `제품 보기` 링크 또는 `쇼핑하기` 상품 카드를 기준으로 한다. 페이지 하단의 “크리에이터들이 … 태그 또는 추천한 상품” 고지문은 일반 Shorts에도 나타나므로 쇼핑 태그 증거로 사용하지 않는다.

검증 대기열은 검색어별 누적 실측 정밀도를 반영한다. 태그 확인 채널을 자주 찾은 검색어의 미검증 채널을 올리고, 확인 표본에서 오탐이 많았던 검색어는 내린다. 표본 한두 건으로 순위가 급변하지 않도록 Beta(1,1) 보정을 적용하며 최소 3개 감사 표본이 있는 검색어만 점수화한다.

## 근거

- [YouTube Data API `search.list`](https://developers.google.com/youtube/v3/docs/search/list): `q`, `order`, `regionCode`, `relevanceLanguage`, `videoDuration` 동작과 검색 쿼터.
- [YouTube Data API 개요](https://developers.google.com/youtube/v3/getting-started): 기본 검색 호출 및 일일 쿼터 구조.
- [YouTube Shopping 제품 태그](https://support.google.com/youtube/answer/10191533?co=GENIE.Platform%3DDesktop&hl=ko): Shorts 쇼핑 스티커와 제품 태그 표시 방식.
- [YouTube Shopping 제휴 프로그램 팁](https://support.google.com/youtube/answer/15814303?co=YOUTUBE._YTVideoType%3Dshorts&hl=ko): 뷰티·기술·가정·의류 등 쇼핑 카테고리 범위.

검색어 자체는 공개 API의 고정 분류가 아니다. 실제 채널 채택 여부는 전체 영상의 쇼핑성 비율과 Chrome의 `제품 보기` 관찰로 별도 검증한다.

채널 백필은 모든 채널에서 업로드 1페이지를 먼저 수집한 뒤 전체 이력으로 확장한다. 대형 채널 하나의 전체 이력이 API 예산을 독점하지 않도록 표본 범위를 우선한다.
