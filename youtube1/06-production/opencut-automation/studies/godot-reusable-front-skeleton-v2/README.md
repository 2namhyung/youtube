# Godot reusable front skeleton study v2

Private, non-publishable successor to v1. It uses the same 1024x1536 review-front sources, the same joint map, one `Skeleton2D`/`Bone2D` hierarchy, and the same 3-second 7-degree upper-arm / 16-degree forearm gesture for both appearances.

V2 changes only appearance preparation: the flattened source arms are fully removed from the fixed body; upper arm, forearm, and hand are separate named layers; and fixed, outline-free coat/skin underfills overlap every shoulder, elbow, and wrist. This is intended to remove the v1 moving coat-outline ghost and shoulder holes without provider calls or invented in-between frames.

The outputs are private review artifacts, not admitted production media. They do not replace the approved three-quarter authority and do not authorize upload or publication. Human full-resolution review remains required; any visible ghost, gap, tear, thickness jump, or pose drift fails this study honestly.
