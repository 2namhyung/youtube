# Generic character Plastic rig study v1

Private, non-publishable 3-second character-action study.

- Character authority: `master-approved-v1-alpha-v4.png`
- Rig authoring: OpenToonz 1.8 Plastic mesh and skeleton
- Motion: keyed Plastic vertex channels; no generated in-between images and no frame swapping
- Render: OpenToonz `tcomposer.exe`, frames 1–72 at 24 fps using a native 1080x1920 camera
- Intended test: a restrained right-hand explanatory gesture returning toward rest

This study is not admitted production media. A single flattened raster mesh is suitable only for small gestures: large limb rotations can fold or tear the texture. Production-scale acting requires separated, overlapping body-part artwork or a redrawn pose library before rigging.
