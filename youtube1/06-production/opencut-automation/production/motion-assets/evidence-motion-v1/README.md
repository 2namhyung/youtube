# evidence-motion-v1

Small, auditable first acquisition batch for the evidence-led Korean vertical-news pipeline. Snapshot date: **2026-08-12**. Every downloaded file is under `sources/`; upstream license/terms pages are preserved under `licenses/`. `manifest.json` is generated by `build-manifest.mjs` and records byte size, SHA-256, non-symlink status, source URL, license URL, role, ingest note, and any remote URLs found in text sources.

## What is physically present

### Must-use (free/legal/direct)

- **Lucide SVG icons (ISC)** — `sources/lucide/icons/`: `smartphone`, `map-pin`, `hospital`, `activity`, `stethoscope`, `file-text`, and `clock-3`. These are tiny editable SVGs with `currentColor`, so they can be recolored in a deterministic Node/FFmpeg render. Use `smartphone`/`file-text` for the 휴대전화 story, `hospital`/`stethoscope`/`activity` for 간호조무사, and `map-pin`/`clock-3` for Jeju/location/timeline cues. License: <https://github.com/lucide-icons/lucide/blob/main/LICENSE>.
- **Natural Earth map extracts (public domain)** — `sources/natural-earth/ne_110m_admin_0_countries.zip` (small world locator) and `ne_10m_coastline.zip` (detailed coastline). Convert the Shapefile contents once to an authority-bound SVG/GeoJSON layer; do not use the ZIP directly in the renderer. The 10m coastline is suitable for a restrained Jeju outline; these are not legal-boundary or incident evidence. Terms: <https://www.naturalearthdata.com/about/terms-of-use/>.
- **Poly Haven diffuse plates (CC0)** — `sources/polyhaven/wood_floor_diff_1k.jpg` and `concrete_floor_01_diff_1k.jpg` (1K, about 0.7 MB each). They are visually inspectable neutral grain for paper/evidence cards after a deterministic crop, desaturation, and blur. Poly Haven asks that products using the live API identify Poly Haven; the CC0 files themselves remain reusable. License: <https://polyhaven.com/license>; API terms/metadata snapshots: `sources/polyhaven/*.files.json`, <https://polyhaven.com/our-api>.

## Ingest contract

1. Treat `manifest.json` as the handoff inventory. Re-run `node build-manifest.mjs` only after a deliberate source refresh; a missing file or symlink fails the script.
2. For SVG/JPG/WAV, ingest by exact relative path and verify the manifest SHA-256 before use. For Natural Earth, unpack outside runtime and create a deterministic, case-specific vector derivative whose authority hash is recorded by the normal creator/verifier flow.
3. Keep all text-source URLs out of runtime bundles. The only URLs detected in this snapshot are HyperFrames CDN dependencies and catalog/API metadata; they are explicitly source-only.
4. Preserve attribution in release metadata: Lucide ISC notice, “Made with Natural Earth” (optional but recommended by Natural Earth), and a clear Poly Haven credit when the API or textures are visible. Do not imply that any reference map/thumbnail proves an incident claim.

## Case mapping

- **제주**: Natural Earth 110m locator → 10m coastline detail → Lucide `map-pin` and `clock-3`; use Poly Haven concrete/wood only as a low-contrast evidence-card texture. Replace the illustrative HyperFrames NYC–Paris map before publication.
- **간호조무사**: HyperFrames `flowchart` as a timing/layout reference, Lucide `hospital`, `stethoscope`, and `activity`, plus `data-chart` for source-backed counts. Korean labels and all numbers must come from approved evidence, not catalog defaults.
- **휴대전화**: Lucide `smartphone`/`file-text`, HyperFrames `caption-clip-wipe` for word-level emphasis and `flash-through-white` for a short separation beat. Localize dependencies before use.

## Explicitly deferred/rejected

- Pexels, YouTube Audio Library, and Sonniss were not downloaded: account/Studio/API or bundle-license/size constraints make a no-account first batch less auditable.
- Motion Canvas, HTML/CSS/SVG/Canvas, GSAP, Lottie, Three.js, D3, MapLibre, and commercial After Effects/Premiere/Resolve libraries remain **evaluate** candidates for a later dependency-pinned source review; no package-manager install or remote runtime dependency is introduced here.
- OSM/MapTiler live tiles are deferred because tile-policy/API attribution and offline/headless redistribution rules require a separate authority decision. Natural Earth is the safe map seed for this batch.
