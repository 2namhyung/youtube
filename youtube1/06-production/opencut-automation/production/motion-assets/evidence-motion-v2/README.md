# evidence-motion-v2

Second, source-first acquisition batch for the Korean vertical documentary pipeline. Snapshot date: **2026-08-12**. This directory is independent of v1 and pipeline code. `manifest.json` is generated by `build-manifest.mjs`; it inventories every file under `sources/` with exact source URL, license URL, byte count, SHA-256, editability, role, remote-dependency flag, and non-symlink status.

## Ingest and safety rules

1. Run `node build-manifest.mjs` from this directory after any deliberate refresh. It refuses symlinked source files and rewrites `manifest.json` with SHA-256 and remote dependency evidence.
2. `admission: direct-source` means the bytes are directly downloadable with a recorded permissive/public-domain license and no detected runtime URL. `source-only` means code, metadata, a fixture, a large reference, or a file with CDN/remote dependencies; it must be vendored/pinned and separately attested before rendering.
3. No downloaded repository example, fixture, template, or catalog code is executable production authority. Separately authored adapters under `production/motion-engines/nonhuman-runtime-v1` use pinned official packages only; the verified `newsroom-deterministic-motion-engines-v1` authority admits Motion Canvas core, GSAP, Lottie-web, dotLottie-web, Canvas/D3, local Edge HTML/SVG, and FFmpeg keyframes with network blocked and exact frame seeking. This promotion does not promote any file in this source catalog.
4. Keep Korean fonts and all license notices in release provenance. Credit NARA and the CC BY teleprinter author when those assets are used. Do not use a generic icon, NARA image, or map demo as evidence of a real incident.
