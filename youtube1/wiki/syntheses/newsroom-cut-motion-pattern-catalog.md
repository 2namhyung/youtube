# 뉴스룸 2–3초 컷 모션 패턴 카탈로그

- 기반 자료: [모션 레퍼런스 조사](../sources/motion-reference-cut-mechanics-2026-08-15.md)
- 적용 범위: 1:1 미디어 영역, authored duration 2–3초
- 원칙: 한 컷에는 **주 동작 1개**, 필요하면 **전환 1개**만 둔다. 정보가 읽히기 전에 두 번째 동작을 겹치지 않는다.
- 실제 Shorts 편집 적용: [짧주 분석 기반 스토리보드 개선](short-form-storyboard-upgrades-from-shortju.md). 이 분석은 hard cut과 실제 이미지의 정보 역할을 기본값으로 두고, 모션 패턴은 정보가 부족한 컷에만 선택하도록 보완한다.

## 컷 내부 패턴

| ID | 패턴 | 2.5초 예시 | 적합한 뉴스 정보 |
|---|---|---|---|
| IN-01 | marker highlight | 0–0.45초 본문 rise → 0.45–1.0초 선 draw → 1.0–2.5초 hold | 법 조항, 문서 핵심, 반박 문장 |
| IN-02 | headline slam | 0–0.55초 scale 1.6→1 + 3프레임 진동 → 2.1초 hold → 0.4초 exit | 질문, 반전, 핵심 수치. 남용 금지 |
| IN-03 | route / connector draw | 0–0.25초 기준점 → 0.25–0.95초 선·노드 → 2.5초 hold | 이동, 전달, 수사 흐름, 인과관계 |
| IN-04 | comparison split | 0–0.25초 setup → 0.25–1.3초 divider wipe → 2.5초 split hold | 전후 비교, 진술 대 기록, 1심 대 2심 |
| IN-05 | one-metric chart | 0–0.3초 축 → 0.3–1.6초 막대/선 하나 → 2.1초 callout → hold | 건수, 비율, 형량 변화 |
| IN-06 | constellation hub | 0–0.25초 hub → 0.25–0.95초 연결선·노드 → hold | 인물·기관·사건 관계. 노드 최대 3개 |
| IN-07 | photo annotation | 0–0.35초 사진 정착 → 0.35–0.9초 라벨/선 → 2.5초 2% push | 실제 장소·기관·물건 자료사진 |
| IN-08 | reconstruction layers | 0–0.45초 첫 조각 → 0.45–1.4초 2–3개 결합 → hold | 대본에서 생략된 절차·사건 구조 |
| IN-09 | bubble trend | 0–0.2초 축·범례 → 0.2–1.7초 한 시점 이동 → final hold | 시간에 따른 집단 변화. bubble 4–8개 |
| IN-10 | timeline / three beats | 0–0.35초 rail → 0.35–1.9초 3개 사건점 → hold | 신고→수사→송치, 사건 발생→재판→결과 |

## 컷 전환 패턴

| ID | 전환 | 권장 길이 | 선택 조건 |
|---|---|---:|---|
| TR-01 | hard cut | 2–4프레임 | 사실·장소가 바뀌거나 속도를 올릴 때 |
| TR-02 | cut-on-action | 2–6프레임 | 사람이나 소품의 방향이 다음 컷에서도 이어질 때 |
| TR-03 | position / silhouette match cut | 0.08–0.25초 | 같은 대상 또는 같은 위치의 다른 상태를 연결할 때 |
| TR-04 | directional paper wipe | 0.35–0.70초 | 이동 방향·절차 방향이 분명할 때 |
| TR-05 | foreground occluder | 0.15–0.45초 | 문서·문·차량·소품이 화면을 실제로 가릴 때 |
| TR-06 | push / slide | 0.35–0.60초 | 이전 정보가 밀려나고 다음 단계가 들어올 때 |
| TR-07 | zoom-through | 0.35–0.60초 | 전체→세부 또는 장소→증거처럼 스케일 관계가 있을 때 |
| TR-08 | shape morph | 0.60–0.90초 | 의미가 이어지는 아이콘·상태 사이에서만 |
| TR-09 | color flash / alert | 2–4프레임 | 위험·경고의 단일 강조. 광과민성·남용 주의 |
| TR-10 | dissolve | 0.25–0.60초 | 시간 경과·기억·불확실성을 나타낼 때만 |

## 배정 규칙

1. **실제 사진 중심 컷**: IN-07을 기본으로 하고, 사진 자체의 증거성을 해치지 않는 crop·2% push·라벨만 허용한다. 전환은 TR-01, TR-03, TR-05를 우선한다.
2. **대본 누락 정보 보완 컷**: IN-01, IN-03, IN-04, IN-08, IN-10 중 하나를 골라 뉴스 원문이나 법·기관 자료의 claim lineage와 결합한다.
3. **사람 행동 컷**: 행동은 생성 영상에서 수행하고 컷 전환은 TR-02 또는 TR-05로 연결한다. 정보 그래픽을 사람 행동 위에 동시에 여러 개 얹지 않는다.
4. **수치·관계 컷**: IN-05, IN-06, IN-09를 사용하되 한 컷에서 지표 하나 또는 관계 하나만 설명한다.
5. **방향 일관성**: 원인→결과와 과거→현재는 좌→우, 상위기관→하위 절차는 위→아래를 기본으로 하되 실제 지리 방향이 있으면 지리를 우선한다.
6. **정지 구간**: 핵심 상태가 최소 0.7초는 안정적으로 보여야 한다. 2–3초 전체를 계속 움직이지 않는다.
7. **텍스트 안전영역**: 제목과 자막은 미디어 사각형 밖의 canonical title/caption track에서 처리한다. 사각형 내부에는 짧은 source chip·숫자·라벨만 둔다.

## QA 체크

- 첫 프레임, 최대 변화 프레임, 마지막 프레임에서 정보 상태가 서로 구분되는가?
- 전환 방향이 이야기의 이동·인과·시간 방향과 일치하는가?
- 동작을 제거했을 때도 claim이 맞고, 동작을 넣었을 때 이해가 빨라지는가?
- 실제 사진을 사건 당사자·현장으로 오인시키는 animation이나 caption이 없는가?
- 2–3초 안에 주 동작이 끝나고 최소 0.7초의 읽기 구간이 남는가?
- 원본 레퍼런스의 프레임·로고·팔레트·음원을 복사하지 않았는가?
