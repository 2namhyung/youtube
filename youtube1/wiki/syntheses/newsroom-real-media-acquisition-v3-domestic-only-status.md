# Newsroom domestic-photo-only acquisition v3 status

Captured 2026-08-15. The user requires all real photographs for the three remakes to be domestic: a Korean institution/rightsholder must be the origin and the capture context must also be Korea. A Korean subject on a foreign host and a foreign photograph on a Korean page are both excluded.

The sealed successor needs artifact is [newsroom-real-media-needs-v3-domestic-only](../../06-production/opencut-automation/out/studies/newsroom-real-media-needs-v3-domestic-only/run-20260815T115202Z-8c012a/photo-needs.json). It retains the storyboard-first allocation of 46 distinct real-photo cuts: police 16, Jeju 15, nurse assistant 15. Each need has a Korean-language search query and requires `originCountry=KR`, `captureCountry=KR`, and a Korean rightsholder.

The primary automated route is the official KOGL search and item page. Only an item-level KOGL Type 1 photograph with a named Korean institution, a preserved detail-page hash, a decodable minimum-edge-480 source, and a unique SHA-256/pHash can be admitted by the collector. KOGL 2/3/4, unknown rights, foreign sources, foreign capture context, HTML masquerading as an image, duplicates, and undersized sources fail closed. Police and other institutional pages remain eligible only when their item itself carries KOGL Type 1 or written clearance; a site-wide copyright policy is not an item license.

The former complete Wikimedia acquisition is now explicitly `domestic-policy-ineligible`. It is preserved and not deleted, but cannot seed or satisfy this route. No admission, provider, render, upload, publication, or Stage 07 action is authorized until all 46 domestic photos and an independent physical/rights verifier pass.

The latest structurally verified acquisition is [run `20260815T124410Z-expanded-becf55`](../../06-production/opencut-automation/out/studies/newsroom-real-media-acquisition-v3-domestic-only/run-20260815T124410Z-expanded-becf55/manifest.json), with its [independent verifier](../../06-production/opencut-automation/out/studies/newsroom-real-media-acquisition-v3-domestic-only/run-20260815T124410Z-expanded-becf55/acquisition-verifier.json). It physically verifies 24 distinct domestic KOGL Type 1 files: the prior 21 plus three new Jeju-context candidates. Twenty-two cut slots remain empty. All 24 remain `conditional`, `coverageEligible=false`; structural verification is not semantic approval.

The expansion audit found and corrected a collector defect: KOGL's `searchPageType=M` returns recommendation material and can ignore the intended cut query. The successor now uses the official result-page request mode `searchPageType=S`, `sort=ddate`, cut-specific aliases, and a title-anchor gate. An earlier 31-file run that used the recommendation mode is retained only as rejected audit evidence and is not a predecessor. Visual inspection of the three new files found one plausible Jeju government-building context photo and two weak school-context matches; none was promoted. The original 21 also remain pending replacement or per-cut visual approval—particularly the repeated historical fisheries-laboratory series, which cannot be counted as fifteen distinct hospital-story semantics merely because the bytes differ. `complete=false` and `admissionAuthorized=false` are therefore correct.

## Shared-work collection expansion

The official Korea Copyright Commission Shared Work item pages expose an item-bound original download (`wrtFileDownload.do?wrtSn=...&fileSn=1`) and a separate rights page. A new append-only collection used that path only after each detail page explicitly stated CC BY 4.0, named the Korean rightsholder, and declared the source dimensions. The complete [21-source collection manifest](../../06-production/opencut-automation/out/studies/gongu-domestic-photo-expansion-v1/run-20260815T131609032Z-a6e887/manifest.json) preserves each original, detail-page bytes, SHA-256, decoded dimensions, pHash, attribution, and cut binding. Its [independent verifier](../../06-production/opencut-automation/out/studies/gongu-domestic-photo-expansion-v1/run-20260815T131609032Z-a6e887/verifier.json) passes.

Human visual QA did not equate successful downloading with editorial fitness. The [sealed visual review](../../06-production/opencut-automation/out/studies/gongu-domestic-photo-visual-review-v1/run-20260815T131816008Z-6fc851/visual-review.json) approved 10 candidates, made one school-corridor image conditional on cropping or blurring a distant person, and rejected 10. Approved candidates cover Korean classrooms/desks, Korean school corridors, a Korean-road police vehicle, and Korean-shot coffee. Rejections include identifiable generic office actors, architecture where the alleged CCTV was not actually visible, semantic mismatches, and sensitive patient imagery. These are candidate additions, not production admission; they do not retroactively turn the older 24-file manifest into a complete 46-cut set.

Photo Korea has an official item catalogue and API, but account/API-key and use-purpose controls remain real gates. The public 2025 regional XLSX was preserved for reproducible discovery, but its sampled 1,000 rows did not contain useful school/police/court/hospital candidates for the sealed cuts. AKS exposes a media OpenAPI for Korean schools, courts, and police facilities, but requires an issued `X-API-Key`; item media may be used only when its own public-use mark is confirmed. No secret file was read and no authenticated call was made.

Official sources: [Shared Work CC guide](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200093), [Shared Work API guide](https://gongu.copyright.or.kr/gongu/useReqst/apiKey/info.do?menuNo=200245), [Photo Korea](https://phoko.visitkorea.or.kr/main/index.kto), [Photo Korea OpenAPI](https://www.data.go.kr/data/15101914/openapi.do), [AKS OpenAPI](https://encykorea.aks.ac.kr/Guide/OpenApiUse), [AKS content-use policy](https://encykorea.aks.ac.kr/Guide/ContentUse), [KOGL license types](https://www.kogl.or.kr/info/license.do), and [National Police copyright policy](https://www.police.go.kr/www/guide/copyright.jsp).
