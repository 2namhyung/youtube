# 02 맥락·법률 분석

- 상태: 부분 운영 (75%)
- 입력: 01에서 승인한 사건, 기사 원문, 확인된 행위
- 처리: 잠정 혐의 → 후보 혐의 구성요건 → 빠진 증거 → 피해자 보호 공백 → 검증 가능한 유사 판례·사례 → 안전한 대본 문장
- 출력: `chargeGapResearch`, `fearAnalysis`, `legalResearch`
- 처리: 최신 event dossier 기반 자동 법률 결과(allow·conditional·block)
- 동작: Stage 02 GET은 변경하지 않으며, 누락·오래된 보고서만 클라이언트의 단일 POST/PATCH로 재생성
- 다음 단계: allow·conditional은 승인 없이 즉시 대본 생성 CTA를 제공하고, block은 대본 생성을 차단
- 유사 판례 검색 결과가 0건이어도 검색 부재와 한계를 명시하면 첫 번째 검토는 완료한다. 이 결과는 `유사 판례가 존재하지 않는다`는 뜻이 아니며, 대본에는 특정 죄명·형사책임·처벌·향후 수사 결과를 단정하지 않는 제한을 적용한다. 판례가 없다는 이유만으로 Stage 03을 영구 차단하지 않는다.

제주 사건에서는 텀블러 등 물건 오염이 강한 성적 모욕감과 공포를 주더라도 그 사실만으로 특정 성범죄가 자동 성립한다고 단정할 수 없다는 간극을 다룹니다. 공개 자료에서 최종 죄명·처분은 확인되지 않았습니다. 현재 구조화 자료는 [project.ts](../../06-production/opencut-automation/opencut-classic/apps/web/src/newsroom/project.ts)에 있고, 실제 대본 생성 API도 이 자료를 보조 근거로 사용합니다.

법률 정보는 편집 지원용이며 개별 사건의 법률 자문이나 유죄 판단을 대신하지 않습니다.
