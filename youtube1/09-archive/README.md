# 09 아카이브

게시본 또는 폐기본의 조사 근거, 법률 분석, 대본, 음성, 영상 자산, BGM, OpenCut 프로젝트, QA, 업로드 응답을 manifest와 체크섬으로 함께 보존합니다.

- 기존 압축·과거 산출물은 삭제하지 않고 이 폴더에 유지합니다.
- 이전 Scratch/Vendor는 [`legacy-support`](legacy-support)에 보존했습니다.
- 이전 8단계 위키 페이지는 [`legacy-wiki-pipeline-pages`](legacy-wiki-pipeline-pages)에 보존했습니다.
- 복원 시 운영 경로에 바로 덮어쓰지 않고 별도 작업 폴더에서 검증한 뒤 새 버전으로 승격합니다.

현재 제주 59.97초 렌더는 완전한 9단계 아카이브 manifest가 없어 정식 보관 승격 전입니다.
