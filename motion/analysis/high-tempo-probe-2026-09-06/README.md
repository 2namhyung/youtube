# High-tempo T1 probe

Tokyo person component only, rendered from the existing v2 source at 1.50x, 1.80x, and 2.00x. Each candidate is 720x1280, 24fps, 48 frames / 2.0s, beginning at source 3.5s. The source window is 3.5–6.5s, 3.5–7.1s, and 3.5–7.5s respectively.

The comparison uses the reference's 4.95–6.35s interval and the first 1.4s of each candidate. It is 4 columns at 540x1080 (2160x1080 total), exported at 120fps by frame duplication only; there is no optical-flow interpolation. Exact step counts were not independently measured.
