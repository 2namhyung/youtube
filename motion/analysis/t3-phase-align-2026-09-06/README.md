# 보행 위상 조정 후보 — 2026-09-06

## 결과

전체 영상을 잘라 연결하는 대신 의상별 인물 소스의 시작점을 변경하고 기존 카드 전환으로 재합성했다. Flow 재생성은 수행하지 않았다.

- 채택 후보: 아오자이 소스 시작 6.000 → 5.750초, 명목 끝 9.350초.
- 유지: 인물 1.80배속, 13초 길이, 다른 도시 소스 시작점, 카드 형상·마스크·전환 시각, 원본 오디오.
- 기모노→치파오: 치파오 시작점 2.375/2.500/2.625초 비교에서 확실한 개선을 확인하지 못해 2.500초 유지.
- 치파오→아오자이: 실제 발 교체 직전·직후 프레임에서 앞발의 화면상 위치 점프가 줄어든 것으로 보이는 후보. 완전한 보행 연속성 PASS가 아니다.

## 해석과 한계

카드가 아래에서 상승하는 현재 합성에서는 발 영역이 전환 시작 후 첫 1~2프레임에 새 인물로 교체된다. 따라서 전환 중간 포즈만 비교하면 실제 연결 지점을 놓친다.

이번 변경은 인물 전체 소스의 시간 오프셋이다. 다리만 독립 수정한 것이 아니므로 상체·소품 동작 시점도 함께 이동한다. 모자를 쓰는 후반 구간은 포함된다. 발 위치뿐 아니라 이동 방향·속도·접지 타이밍도 맞아야 최종 합격이며, 해부학적 발 추적이나 모든 경계의 연속성을 인증한 결과는 아니다. 다른 전환은 미해결 상태를 그대로 보존했다.
