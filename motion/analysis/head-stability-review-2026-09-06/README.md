# Head stability review

Bounded visual review only. The contact sheet crops face/head/upper trunk from selected frames of the reference, current Seoul/Tokyo 10-second sources, and the provisional T3 candidate. It tests whether the reference is consistently lens-facing and whether suppressing upper-body action is a sound correction.

Eye direction is not directly measured. Exact speed causality is not established. No source, production, wiki, Flow, or generated media file was modified; this is evidence for a provisional design decision, not an approval.
