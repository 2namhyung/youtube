# Reference vs T1 tempo comparison

작성일: 2026-09-06

이 폴더는 레퍼런스의 안정적인 Bangkok 구간(4.95–6.35초)과 기존 T1 인물 단독 후보(1.00×, 1.10×, 1.20×)를 같은 1.40초 출력 구간으로 나란히 확인하기 위한 진단 산출물이다. 레퍼런스의 실제 배속 계수나 정확한 보폭 수를 확정하는 자료가 아니다.

## 방법과 표시 한계

레퍼런스는 원본 30fps에서 4.95초를 시작점으로 읽었고, T1 후보는 원본 24fps의 동일 출력 시각을 읽었다. 네 스트림은 120fps 컨테이너로 맞췄지만 프레임 보간이나 레퍼런스 재배속은 적용하지 않았다. 표시만 각 패널 540×1080으로 scale/pad 했으며, 기하를 변형하지 않고 흰 여백을 넣었다. 레퍼런스는 거대한 카드 안의 인물, 후보는 흰 스튜디오 전신 인물이므로 인물의 픽셀 크기와 배경 맥락은 완전히 동일하지 않다.

## 관찰

레퍼런스에서는 0.00–1.35초 동안 다리 벌어짐·모임·후방 발 들림이 빠르게 진행되고, 0.80초 무렵 이미 뚜렷한 후방 다리 굽힘이 보인다. T1 후보는 1.00×에서 세 후보 중 진행이 가장 느리고, 1.10×는 중간, 1.20×는 빠른 리듬 쪽으로 가장 접근한다. 그러나 서로 초기 phase와 보폭 진폭이 달라 레퍼런스와 템포가 일치한다고 검증할 수는 없다. 이는 접지점을 동일하게 추적한 수치가 아니라, 같은 시각 샘플에서 확인한 포즈 진행의 질적 비교다.

후보 간에는 1.20×가 더 빠른 보행 진행을 보여도 보폭 진폭 자체를 키우지 않으며, 얼굴·상체·우산·의상 후속동작도 함께 빨라진다. 따라서 “1.20×가 레퍼런스 배속”이라고 결론내릴 수 없고, 실제 통합 전에는 상체가 급해지는지 확인해야 한다.

발 접지 이벤트는 양쪽 영상의 복장·카드 가림·시점이 달라 동일한 좌우 발 접지 또는 반복 포즈 시간을 신뢰성 있게 정렬할 수 없었다. 그러므로 steps/sec, 주기, 배속 오차는 **NOT_MEASURABLE**로 기록한다. 본 비교의 결론은 “1.10–1.20× 후보를 우선 검토하되, 1.20×를 확정하지 않는다”이다.

## 다음 결정

T1의 다음 검토 후보는 1.10×와 1.20×다. 1.20×에서 손·우산·표정이 급해지거나 보행이 여전히 작으면 Flow의 보행 수정(T2)으로 이동한다. 전체 13초에 적용할 때는 현재 약 10초 도시 소스로 1.20× 9.5초 구간을 소비하면 11.4초가 필요하므로, 긴 연속 소스 없이는 정지·반복·리셋으로 채우지 않는다.
